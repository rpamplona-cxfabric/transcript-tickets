# CXF Transcript Tickets

A Next.js workspace for reviewing customer call transcriptions and managing the support tickets created from them.

## Local setup

Install dependencies:

```bash
npm install
```

Copy the environment template and add your Auth0 values:

```bash
cp .env.example .env.local
```
## Run the app

```bash
npm run dev
```

Open [http://localhost:4400](http://localhost:4400).

## Verification

```bash
npm run lint
npm run build
```
